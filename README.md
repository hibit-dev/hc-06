# Getting started with the HC-06 Bluetooth module
The HC-06 is one of the simplest ways to add wireless communication to an Arduino project. It's an affordable Bluetooth 2.0 module that behaves like a plain serial port, so once it's wired and configured, sending data over the air works exactly the same way as writing to the serial console. There's no complex protocol stack to learn and no special library to install. It's a slave-only device, which means it waits for a phone, computer, or another Bluetooth host to connect to it rather than initiating connections on its own. For the majority of hobby and prototyping work, that's exactly what's needed.
